# SEO-чеклист Котоматики

Готово:
- Уникальные title и meta description для основных страниц.
- Canonical URL.
- robots.txt.
- sitemap.xml.
- Open Graph / Twitter Card.
- JSON-LD: EducationalOrganization, BreadcrumbList, FAQPage и Person-шаблоны.
- Отдельные SEO-страницы для 5–11 классов.
- Отдельные URL под преподавателей.
- Семантические H1/H2/H3.
- Внутренняя перелинковка.
- Alt-тексты.
- Адаптивность.
- Базовая оптимизация структуры и скорости.

Перед публикацией:
1. Если домен отличается от https://kotomatika.ru, заменить BASE во всех HTML/canonical/OG/sitemap/robots.
2. Заменить все [placeholder] в преподавателях, отзывах, ценах и контактах.
3. Добавить реальные фото преподавателей в WebP/AVIF и описательные alt.
4. Подключить backend/CRM к /booking/.
5. Создать и разместить Политику конфиденциальности и Пользовательское соглашение.
6. Добавить Яндекс Вебмастер и Google Search Console.
7. Отправить sitemap.xml в обе панели.
8. Проверить robots.txt, canonical, 404, редиректы и мобильную версию.
9. Добавить реальные URL Telegram/VK/email.
10. После появления реальных профилей преподавателей убрать noindex/disallow для их страниц и добавить их в sitemap.

Важно: страницы преподавателей сейчас специально сделаны как редактируемые шаблоны и не включены в sitemap, пока в них нет реальных данных.
