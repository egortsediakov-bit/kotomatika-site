# КОТОМАТИКА — публикация и заявки

## Публикация
Эта сборка совместима с GitHub Pages в репозитории `kotomatika-site`.
Загружайте содержимое папки `KOTOMATIKA_TEST` в корень репозитория.
GitHub Pages: branch `main`, folder `/ (root)`.

## Заявки
Текущая цепочка:
сайт -> Yandex Cloud Function -> Google Apps Script -> Google Sheets.

URL Yandex Function хранится в `config.js`.
Секретов Telegram в проекте нет.

Google-таблица: «Заявки КОТОМАТИКА».
Колонки: дата и время, родитель, ученик, класс, цель, контакт, комментарий, источник, статус.

## Важно
Перед коммерческим запуском необходимо отдельно проверить юридическую схему обработки
персональных данных, включая требования локализации и трансграничной передачи.
