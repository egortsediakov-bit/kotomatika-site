# Котоматика — SEO-версия сайта

Статический многостраничный сайт, основанный на визуальном стиле логобука Котоматики.

## Запуск локально
Для корректной работы абсолютных URL и assets лучше запускать через локальный HTTP-сервер:
`python -m http.server 8000`
и открыть `http://localhost:8000/`.

## Структура
Главная, О школе, Преподаватели, профили преподавателей, Направления, ОГЭ, ЕГЭ, Индивидуальные занятия, Отзывы, Цены, FAQ, Контакты, Запись, плюс SEO-страницы 5–11 классов.
