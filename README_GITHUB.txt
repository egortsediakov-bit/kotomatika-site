КОТОМАТИКА — исправленная сборка для GitHub Pages

ЭТА ВЕРСИЯ ИСПРАВЛЯЕТ:
— стили CSS;
— JavaScript;
— фотографии;
— внутренние ссылки при публикации в репозитории kotomatika-site.

Ссылки сделаны относительными, поэтому эта же сборка будет работать:
1) на https://<логин>.github.io/kotomatika-site/
2) после подключения собственного домена kotomatika.ru

КАК ОБНОВИТЬ:
1. Распакуйте ZIP.
2. В репозитории kotomatika-site удалите старые файлы или загрузите новые с заменой.
3. index.html должен оставаться в корне репозитория.
4. Commit changes.
5. GitHub Pages уже включён — заново настраивать Pages не нужно.
6. Подождите 1–3 минуты и обновите сайт Ctrl+F5.

Важно:
— форма на бесплатном GitHub Pages копирует текст заявки и открывает Telegram администратора;
— серверное хранение/отправка заявок в этой статической версии не используется.
