КОТОМАТИКА — сборка для GitHub Pages

1. Распакуйте ZIP.
2. В GitHub откройте репозиторий kotomatika-site.
3. Add file → Upload files.
4. Загрузите СОДЕРЖИМОЕ этой папки, чтобы index.html лежал в корне репозитория.
5. Commit changes.
6. Settings → Pages → Deploy from a branch → main → /(root).

Важно:
— эта сборка рассчитана на статический GitHub Pages;
— форма не хранит данные на сервере: текст заявки копируется и открывается Telegram администратора;
— перед коммерческим запуском проверьте политику конфиденциальности с юристом;
— реальные видео можно добавить позже в assets/video/.
